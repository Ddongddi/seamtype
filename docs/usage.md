# 쓰는 법

[← README](../README.md) · 한국어 · [English](usage.en.md)

## 키

치고 있는 단어에는 밑줄이 그어지고, Seamtype이 예상한 언어로 보입니다.

| 키 | 영어·한국어 단어 | 일본어 구절 |
| --- | --- | --- |
| 글자 | 단어를 이어서 침 | 구절을 이어서 침 (가나로 미리 보기) |
| **[언어 바꾸기 키](#언어-바꾸기-키)** (기본: 오른쪽 ⌥ 단독으로 눌렀다 떼기, ⇧Esc) | 읽기 바꾸기: 영어 → 영어+조사 → 한국어 → 일본어 | 같음 (라이브 변환이면 먼저 가나로) |
| Esc | 확정, 앱이 Esc를 받음 (언어 바꾸기 키로 골랐으면 위와 같음) | 라이브 변환이면 먼저 가나로 |
| Delete | 영어: 마지막 글자 지우기. 한국어: 치고 있는 글자는 자모 하나씩, 그 앞 글자는 한 글자씩 (한국 → 한구 → 한ㄱ → 한 → 지움, 시스템 두벌식과 같음) | 가나 한 글자씩 (かんこく → かんこ) |
| **Space** | 확정, 그리고 띄어쓰기 | **한자로 변환** (후보 창) |
| `, . ? !` 등 기호 | 확정, 그리고 그 키 | 구절에 붙어 전각으로: 、。？！ （）＿ 「」(`[ ]`) ・(`/`) 〜(`~`) |
| `-` | 확정, 그리고 `-` | ー |
| Return | 확정만 (줄바꿈·전송은 한 번 더 누르기, 설정에서 바꿀 수 있음) | 보이는 대로 확정: 가나, 라이브 변환이면 한자 (줄바꿈 없음) |
| ⌃K / F7, ⌃J / F6 | (앱의 단축키) | 가타카나 / 히라가나 (Space로 전환, Return으로 확정) |
| Tab, 방향키, ⌘/⌃/⌥ | 확정, 앱이 그 키를 받음 | 같음 |
| **오른쪽 ⌘** (단독으로 눌렀다 떼기) | 이 입력창에서 일시정지 / 다시 켜기 | 같음 |

일본어 다음에 따로 친 기호도 일본어 입력기처럼 전각으로 밑줄 친 채 남습니다(`！`, `＿`, `「`). Return으로 확정하고(줄바꿈 없음), Space로 다른 모양(`!`, `‼︎`, `『`…)을 고르고, 글자를 이어 치면 확정되고 새 단어가 시작됩니다. 숫자 사이(`3.5`, `10:30`)는 반각 그대로이고, 전각으로 연 괄호는 영어 단어 뒤에서도 전각으로 닫힙니다(`日本語（English）`).

일본어를 켜 두면 숫자와 기호도 일본어로 칠 수 있습니다. 문장 첫머리나 한국어·영어 뒤에서 따로 친 숫자나 기호는 반각으로 들어가지만, 바로 언어 바꾸기 키를 누르면 일본어 쪽 모양으로 밑줄 친 채 바뀝니다(`123` → `１２３`, `[` → `「`, `?` → `？`). 일본어 문장에서 숫자 바로 뒤에 붙여 친 단어는 조수사로 읽고, Space로 변환할 때 숫자까지 함께 변환합니다(`3ji` → `3時`, `5fun` → `5分`). `5km`, `3pm`처럼 로마자로 읽히지 않는 단위는 영어 그대로입니다.

변환 중(후보 창이 열려 있을 때):

| 키 | 동작 |
| --- | --- |
| Space / ↓, ↑ | 다음 / 이전 후보 |
| ←, → | 첫 문절을 줄이기 / 늘리기 (`今日は｜いいてんき`) |
| 1–9 | 그 후보로 확정 |
| Return | 고른 후보로 확정 |
| Esc / Delete | 가나로 돌아가기 |
| 글자, 문장부호 | 확정하고 이어서 치기 |

변환은 문절 단위입니다. 읽기의 앞부분만 덮는 후보(きょうはいいてんきですね의 `今日は`)를 고르면 그
부분만 확정하고 나머지를 계속 변환합니다.

## 언어 바꾸기 키

읽기를 바꾸는 키는 설정 창의 **키**에서 키 모양 버튼을 눌러 고릅니다. 오른쪽 ⌥ 단독, ⌥Space, 오른쪽 ⇧ 단독, Esc, ⇧Esc
중 여러 개를 고를 수 있고, 기본값은 **오른쪽 ⌥ 단독**과 **⇧Esc**입니다. 고르지 않은 키는 앱으로 갑니다.

- **오른쪽 ⌥ 단독, 오른쪽 ⇧ 단독**: 앱은 modifier 하나만 눌렀다 뗀 것에 반응하지 않으므로, 창을 닫거나
  입력을 지우지 않습니다. 다른 modifier와 함께 오면 받지 않으므로, Raycast나 Karabiner의 Hyper 키(⌃⌥⇧⌘가
  한꺼번에)로 바꾼 키는 원래 묶어 둔 동작을 합니다. 그럴 때는 다른 키를 고르세요.
- **⌥Space**: 원래 줄바꿈 없는 공백을 넣는 키라, 고르면 그 공백은 들어가지 않습니다.
- **Esc**: 손에 익었다면 빠르지만, Claude 데스크톱이나 Slack 같은 Chromium 기반 앱은 입력기가 가져간 Esc도
  따로 받아서 단어를 바꾸는 동시에 창을 닫거나 입력을 취소하기도 합니다. 바꿀 단어가 없으면 앱으로 갑니다.
- **⇧Esc**: 바꿀 단어가 없으면 아무 일도 하지 않고 앱에 가지 않습니다.

앱별 설정에서 앱마다 다른 키를 고를 수 있습니다. 예를 들어 기본으로는 Esc로 바꾸고, 편집기처럼 Esc가
앱에 가야 하는 곳에서만 Esc를 빼면 됩니다. 입력 메뉴의 "Esc로 언어 바꾸기"는 지금 앱에서 Esc만 넣고
뺍니다. 일본어 후보 창과 라이브 변환에서 Esc는 고른 키와 상관없이 먼저 가나로 돌아갑니다.

## 확정한 뒤에 고치기와 학습

Space나 문장부호로 단어를 확정한 직후 언어 바꾸기 키를 누르면 그 단어가 다음 읽기로 바뀌고, 더 누르면
계속 돌아갑니다. Delete로 공백이나 문장부호를 지운 뒤에도 바꿀 수 있지만, 그 밖의 키를 하나라도 누르면
고칠 수 없습니다. 커서가 그 단어 바로 뒤에 있고 앱이 그 자리의 글자를 알려 줄 때만 됩니다.

터미널처럼 그 자리의 글자를 알려 주지 않는 앱에서는 입력 메뉴나 설정 창의 앱별 동작에서 **Space 뒤에도 단어
유지**를 켜세요(`apps.json`의 `holdSpace`). Space가 단어를 끝내지 않고 공백까지 밑줄 안에 넣습니다. 밑줄
친 동안은 치는 중인 단어와 같아서 언어 바꾸기 키로 바꾸고 Delete로 지울 수 있으며(먼저 공백이 지워집니다),
다음 단어를 치기 시작하면 공백과 함께 들어갑니다. Return은 다른 밑줄 친 단어처럼 확정만 하므로 명령을
실행하려면 한 번 더 누르고, 앱이 Space 키를 받지 않으므로 그 앱에서는 텍스트 대치가 동작하지 않습니다.

한 번 고친 것은 그 단어에만 적용되므로 실수로 바꾼 것은 남지 않습니다. 같은 키를 같은 쪽으로 두 번
고치면 그때부터 기억하고, Seamtype이 처음 고른 쪽으로 되돌리면 잊습니다.

## 텍스트 대치

시스템 설정 → 키보드 → 텍스트 대치에 넣은 약어 중 한국어·일본어로 읽히는 것(`주소`, `ㅈㅅ`, `よろ`)은
판단과 상관없이 그 언어로 보여서, Space를 치면 앱이 시스템 입력기에서처럼 바꿉니다. 영어 약어는 원래대로
판단합니다. 일본어 약어는 Space를 누르면 대치할 문구가 첫 후보로 나오고, 같은 약어를 여러 번 넣었다면 문구가 모두
차례로 나옵니다. 바꾸는 건 앱이라, 텍스트 대치를
지원하지 않는 앱(터미널, Chrome 등)에서는 일본어 후보 말고는 바뀌지 않습니다. 목록을 고치면 다음에 입력창을
누를 때 반영됩니다. 일본어 약어는 히라가나 읽기로 넣으세요(`よろ`, `ぐー`).

## 일시정지

터미널의 lazygit, htop처럼 키 하나하나가 명령인 곳에서는 **오른쪽 ⌘**를 단독으로 눌렀다 떼세요. 치던
단어를 확정하고, 그 입력창에서는 키를 친 그대로 넘깁니다. 한 번 더 누르거나, 다른 앱·입력창으로 가거나,
설정을 바꾸면 다시 켜집니다.

누를 때마다 입력 소스를 바꿀 때처럼 커서 아래에 Seamtype 아이콘이 잠깐 뜹니다. 일시정지하면 빗금이
쳐져 있습니다. 메뉴 막대 아이콘은 바뀌지 않으므로, 나중에 확인하려면 입력 메뉴의 체크 표시를 보세요. 이
키는 설정 창의 키에서 끌 수 있습니다.

## vim

neovim은 [`scripts/vim/seamtype.lua`](../scripts/vim/seamtype.lua)를 `~/.config/nvim/plugin/`에,
Vim(8.2 이상, `+job`)은 [`scripts/vim/seamtype.vim`](../scripts/vim/seamtype.vim)을 `~/.vim/plugin/`에
넣으세요. vim이 모드가 바뀔 때마다 Seamtype에 알려 주므로, 입력 모드에서만 단어를 판단하고 노멀·비주얼·
명령줄 모드에서는 키를 바로 vim에 보냅니다. `s`, `dd`, `ciw`, `:wq⏎`가 키마다 바로 실행됩니다. vim
안에서는 Esc가 늘 vim으로 가므로 앱별 설정은 필요 없고, vim을 끝내면 셸에서 다시 단어를 판단합니다.
